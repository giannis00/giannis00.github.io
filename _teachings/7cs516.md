## Overview

This postgraduate module follows data as it outgrows the tools built for small amounts of it. Students start from the relational model and SQL, move to data warehouses and to storage formats and NoSQL systems designed for volume and variety, and then to computation that no longer fits on one machine: MapReduce, Apache Spark and stream processing. Throughout, the emphasis is on understanding what each technology does, measuring what it costs, and judging when it is the right tool and when a simpler one will do.

## Topics

- The relational model, keys, SQL and transactions
- Joins, aggregation and window functions
- Indexes and query plans
- Data warehouses: facts, dimensions and the star schema
- Storage formats: row and column storage, CSV and Parquet
- NoSQL: document and key-value stores, sharding, replication and the CAP theorem
- Processing data that is larger than memory
- MapReduce: divide, map, shuffle, reduce
- Apache Spark: RDDs, DataFrames, Spark SQL and pipelines
- Stream processing: windows and late data
- The cloud, its costs, and end-to-end data pipelines
