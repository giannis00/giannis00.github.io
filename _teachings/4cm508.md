## Overview

This module introduces the fundamental data structures and algorithms of computer science, together with the principles of data management. All programming in the module is carried out in Python. Where Python abstracts away the underlying machine, as in the representation of data in memory or the use of pointers, short C++ examples are used in lectures to make these mechanisms visible; students are not required to write C++.

The first part of the module examines how computers represent data, from number systems and primitive data types to arrays, records and references. It then develops the analysis of algorithms and applies it to searching, to linear data structures and to hashing. The second part addresses sorting, priority queues and graph algorithms, and concludes with an introduction to relational databases, normalisation and SQL.

## Topics

- Number systems and the representation of data in memory
- Primitive data types, variables and control flow
- Arrays, records and references
- Analysis of algorithms and Big O notation
- Searching: linear and binary search
- Linear data structures: dynamic arrays, linked lists, stacks and queues
- Hashing, hash tables and the Map abstract data type
- Sorting algorithms, including divide-and-conquer methods
- Heaps, priority queues and shortest paths in graphs
- Relational databases, normalisation and SQL
